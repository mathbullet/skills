# mathbullet/skills

Claude Code plugin marketplace.

## Install

```
/plugin marketplace add mathbullet/skills
/plugin install research@skills
/plugin install paper-review@skills
```

## Plugins

### research

Multi-source investigation skill. Collects papers, articles, and community discussions into an indexed Markdown report.

```
/research:research <topic>
```

### paper-review

Detailed paper review generator. Creates structured Markdown reviews with proper citations, LaTeX equations, and sections following the original paper.

```
/paper-review:paper-review <paper>
```
