# Paper Review

論文の詳細レビュー（.md）を作成する際に従うべき規範。

## 1. 成果物の構造

### 1.1 冒頭

以下の順に記載する:

1. タイトル（`# {論文タイトル} レビュー`）
2. 書誌情報（著者、所属、venue、年、arXiv/DOI、URL）
3. アブストラクトの全文引用（英語原文をブロック引用で掲載し、直後に独立した段落として日本語訳を置く）

### 1.2 本文の見出し構成

生成するドキュメントの見出し構成は元の論文のセクション構成に従う。論文が Section 1: Introduction, Section 2: Method, Section 3: Results, ... という構成であれば、レビューも同じ順序・同じ見出しで構成する。

レビュー独自のセクション（「論文の強み」「論文の限界」「ソース一覧」等）は、論文のセクション構成の後に追加する。

## 2. 典拠の明示

レビュー中のすべての事実的記述には、それが論文のどこに基づくかを明示する。典拠のない記述は検証不能であり、レビューとしての価値がない。

- 参照は `[著者略称, YYYY/MM]` の形式で本文中に記載する（例: `[ProTeGi, 2023/05, Section 2.1]`）
- セクション番号、ページ番号、Table/Figure 番号のいずれかで位置を特定する
- 番号参照（`[1]`, `[2]` 等）は使わない

## 3. 引用の明示

論文の主張を正確に伝えるために、原文引用をブロック引用で掲載する。要約だけでは、書き手の解釈が正しいか読み手が判断できない。

- 引用の直後に `[著者略称, YYYY/MM, 位置]` を付す
- 英語の引用には必ず日本語訳を付記する。引用ブロックの直後に独立した段落として訳文を置く。括弧で囲んで原文に併記する形式は使わない
- 引用と地の文（書き手の要約・解釈）を明確に区別する

## 4. 数式の記載

- 数式は LaTeX 構文で記載する。インライン数式は `$...$`、ディスプレイ数式は `$$...$$` で囲む
- 厳禁: 数式をコードブロック（``` ``` ```）に書くこと。数式に LaTeX 構文以外（プレーンテキスト表記、疑似コード風表記等）を使うこと
- 例: `$T(n) = k^* \cdot T\!\left(\frac{n}{k^*}\right) + C_{\oplus}(k^*)$`

## 5. 数値結果の記載

- 実験結果はできるだけ表形式で記載する
- 比較対象（ベースライン）と提案手法の数値を並記する
- 数値は論文に記載された値を正確に転記する。四捨五入や概算をしない

## 6. 禁止事項

- 論文に書かれていない解釈・推測・関連づけを書かない
- 「この手法は○○に応用できる」「○○との関連が示唆される」等の独自の接続を付加しない
- レビュー対象の論文の内容記述に徹する。会話の文脈や他のプロジェクトとの関連は書かない

## 7. ソース一覧の書式

レビュー末尾にソース一覧を記載する。形式は以下の通り:

```
[参照ラベル, YYYY/MM] 著者. "タイトル." 媒体名. URL
```

`- [番号]` のリスト形式は使わない。

レビュー対象の論文に加え、レビュー内で言及した他の論文もソース一覧に含める。
