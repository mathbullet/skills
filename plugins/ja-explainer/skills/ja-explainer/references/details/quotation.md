# quotation

論文の詳細解説での引用と出所参照の規範。典拠と引用の共通の規範は、documenting-with-sources スキルと writing-quotation スキルに従う。

## 引用ブロックを主体にする

詳細解説は、論文の本文全体を網羅する「原文の引用と日本語訳」のブロックを主体にして構成する。原文を要約や言い換えで圧縮した地の文を主役にしない。読み手が原文と訳を照合できる状態を、文書全体で保つ。要約だけでは、書き手の解釈が正しいかを読み手が判断できないためである。

地の文は、次のいずれかに当たる場合に限って加える。

- 引用ブロックの間のつながりが不明瞭で、節や段落の関係、論理の流れをつなぐ必要がある場合
- 補足の説明（変数の定義、前提知識、図表の読み方、用語の初出の定義など）が、読み手にとって十分に有用である場合

これらに当たらない箇所では、地の文で原文を要約し直さず、引用ブロックに語らせる。「引用は要点だけにし、本文は地の文で要約する」という配分にしない。

## 出所参照の書式

documenting-with-sources スキルの `[出所ラベル (YYYY/MM), 位置]` のうち、ラベルの埋め方を、解説対象の論文と他の文献とで書き分ける。

- 解説対象の論文を参照する場合は、著者名と年を省き、`[p.X, Section Y.Z]` の形で位置だけを示す（例：`[p.4, Section 1]`、`[p.21, (15)]`、`[p.31, Figure 2]`）。文書全体が1つの論文を対象にしているので、著者名を毎回繰り返す必要はない。
- 解説対象の論文が言及している他の文献を参照する場合は、`[著者略称 (YYYY)]` の形で本文に書く。セクション番号、ページ番号、Table/Figure 番号のいずれかで位置を特定する。
- 論文が言及している個々の文献を省略しない。Related Work などで複数の文献が挙げられている場合も、「○○など」とまとめず、著者名と年を付けて個別に書く。関連文献の一覧は読み手にとって重要な情報であり、解説対象の論文の位置参照では代わりにならないためである。
