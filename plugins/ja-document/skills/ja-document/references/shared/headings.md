# headings

文書の題と見出しの規範。

- 文書の題（H1）には、原文の題を英語のまま書く。
- 原文の章ごとに見出しを立て、見出しの文言は原文の章題を英語のまま使う。読み手は見出しから原文の該当箇所へ戻れるので、本文に位置参照を付けなくてよい。
- 原文にない見出しを書き手が立ててよいのは、原文の1つの章に複数の話題が混在しているのに、原文がその章を節に分けていない場合に限る。この場合は、話題ごとに小見出し（H2）を立てる。たとえば、原文の導入の章が、研究手法の分類、既存の仮説、著者の反論を、節に分けずに続けて論じている場合がこれに当たる。
- 書き手が立てた小見出しの文言は、その節で扱う話題の名前にする（例：`## 既存手法の分類`）。
- 話題の名前が専門用語（[translation.md](translation.md) を参照）である場合に限り、「日本語（English）」の形で書く（例：`## 過学習（overfitting）`）。
