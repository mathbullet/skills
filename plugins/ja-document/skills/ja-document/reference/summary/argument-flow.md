# argument-flow

原文の要点をまとめる日本語の文書の冒頭に置く「議論の流れ」の規範。

- 文書の題の直下に `## 議論の流れ` を1つだけ置き、記事全体の論旨を箇条書きでたどる。
- 「議論の流れ」は、原文を読んでいない読み手が、各箇条を前の箇条から導けるように書く。読み手が原文を読まなければ補えない前提を、箇条と箇条の間に残さない（例：「ソース管理がボトルネックになった」の次に「新しいシステムを構築した」と書くと、なぜ既存のシステムでは対応できなかったのかという前提が抜ける）。
- 各箇条には、記事の主張を1つずつ、完全な文で書く。
- 箇条を上から読むと、論証の筋道が通るように並べる。典型的な順序は「著者の主張 → 分野の通説 → 通説への反論 → 代わりの見方 → 結論」である。
- 論旨をたどるのに必要なものは含め、必要でないものは後続の本文に回す。何が必要かは、2つ目の項目の規則に従って判断する。
- 「議論の流れ」の箇条も、専門用語の初出の箇所に当たる（[translation.md](../shared/translation.md) を参照）。
