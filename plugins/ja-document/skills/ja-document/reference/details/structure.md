# structure

論文の詳細解説の構成の規範。詳細解説の目的は、論文の内容を日本語で正確に詳述することであり、論文を批評・評価することではない。

- 題の直下に、書誌情報（著者、所属、venue、年、arXiv/DOI、URL）を置く。
- 書誌情報の次に、アブストラクトの全文を引用し、日本語訳を添える。
- 本文の章は、論文のセクション構成と同じ順序で立てる。
- 詳細解説に独自の章（「論文の強み」「論文の限界」「ソース一覧」など）は、論文のセクションに対応する章の後に置く。
- 文書の末尾にソース一覧を置く。書式は documenting-with-sources スキルに従う。解説対象の論文に加え、解説の中で言及した他の論文も載せる。
- 論文の図表は、[../shared/figure.md](../shared/figure.md) の「論文の図表の抽出と挿入」に従って、画像として抽出して挿入する。

## 箇条書きと地の文

内容の性質に応じて、箇条書きと地の文を使い分ける。

- 並列的な要素を列挙する場合（変数一覧、評価指標の定義、表の列の説明、手法の比較点など）は、箇条書きにする。羅列的な内容を地の文の段落で書くと、各要素の区切りが見づらい。
- 要素間の関係、議論の流れ、因果関係、文脈を説明する場合は、地の文で書く。なぜそれらが並べられているのか、全体としてどういう議論を構成しているのかを伝える必要があるためである。
