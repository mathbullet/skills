# sentence

日本語の文の組み立て方と、文末と表記の規範。

- 述語は、それが実際に当てはまるものを主語にする。原文の主語をそのまま訳すと、述語がその主語に当てはまらない文になることがある。たとえば、"The canals on Mars were an error" を「火星の運河は誤りだった」と訳すと、運河そのものが誤りだったという文になる。しかし、正しいか誤りかを問えるのは観測や主張であり、運河ではない。誤っていたのは火星に運河があるという観測なので、「火星に運河があるという観測は誤りだった」と書く。
- 「評価」「割合」のように、何についてのものかを文脈に頼る名詞は、対象を補って書く（例：「賛成の割合は90%だった」ではなく「回答者のうち賛成した人の割合は90%だった」）。
- 同じ論点について複数の要因を並べるときは、文ごとの述語の形をそろえる（例：「〜で、数値は変わる。〜によっても結果は大きく変わる。」）。
- 1つの文の後半で主題を切り替えるときは、新しい主題が文の前半のどの語を受けているかが分かる形で書く。前半で修飾語の中に出ただけの語を、後半でいきなり主題に立てると、読み手は何についての述語かをたどり直さなければならない（例：「著者が調べた企業では利益率が高いが、企業は比較的少ない」ではなく、「著者が調べた企業では利益率が高いが、これらは比較的少数の企業である」）。
- 前の文や段落で既に伝わっている情報は、繰り返さない。原文に修飾語として書かれている場合も同様である。
- 英語の thing や something のような汎用的な名詞を、「こと」「もの」と直訳しない。日本語では、こうした名詞を省いたほうが自然になる場合が多い（例："what counts as one thing" は「何を「1つのこと」と数えるか」ではなく「何を「1つ」と数えるか」）。
- 序数や数を表す語が、数そのものではなく「ほかに」「その後に」の意味で使われている場合は、数として訳さない。数として訳すと、原文にない順序や個数を述べているように読める（例："no one has found a second case" は「2つ目の事例を見つけた者はいない」ではなく「その後同様の事例を見つけた者はいない」）。
- 原文が議論の鍵となる命題を述べている箇所は、命題を「」に入れて示す。

## 文末と表記

- である調で書く。
- 副詞、接続詞、形式名詞のように実質的な意味の薄い語は、ひらがなで書く（例：おおむね、ほとんど、ただし、こと）。
