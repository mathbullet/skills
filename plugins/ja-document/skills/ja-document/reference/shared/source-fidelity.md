# source-fidelity

原文を読んで日本語の文書を書くときに、原文の内容をどう扱うかの規範。

- 原文が「何について述べたか」ではなく、「何を述べたか」を書く。手法名、システム名、概念名のような名前を挙げただけでは、その中身を述べたことにならない。「問題を生んだ」「短期間で」のような抽象的な言い方も、何についての話かは伝えるが、何が起きたかは伝えない。
- 原文の記述の範囲に留める。原文に書かれていない因果関係（「この考えから〜が考え出された」など）や、原文より強い言い換えを加えない。
- 原文が一部の事例について述べていることを、分野全体の通説として一般化しない。
- 原文が事態に与えている評価の重さ（大したことではない、決定的である、など）を、訳文でも保つ。評価を担う語（just、only、merely など）を落とすと、主張の強さが変わる。
- 原文の "seems" や "I think" のような著者の推測や判断は、「〜と論じられている」のように、原文の主張として書く。
- 原文の主張は、原文の内容として平叙文で書く。ただし、著者の造語や著者個人の判断であることを示す必要がある箇所では、著者を主語にする。
